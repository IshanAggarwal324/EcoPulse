# Documentation

This folder contains **internal engineering documentation** for the EcoPulse project.

## Audience

- Intended for developers and operators with repository access.
- **Do not** publish these files to a public-facing website without review.
- Deployment topology, architecture notes, and ops runbooks can aid reconnaissance if exposed.

## Public vs internal

| Document | Purpose |
|----------|---------|
| `assistant/*.md` | In-app assistant knowledge base (safe for authenticated users) |
| `EcoPulse_Deployment_Readiness.md` | Internal deployment checklist — keep private |
| `architechture.md` | Internal architecture reference |

For security practices and remediation status, see [`SECURITY.md`](../SECURITY.md) at the repository root.
